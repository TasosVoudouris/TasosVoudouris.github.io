# Reference-source policy

The canonical CryptoCave repository does **not** bundle large third-party paper/PDF libraries or raw incoming source archives.

`homomorphic-private-library-catalog.csv` is retained only as a historical/provenance catalog from the earlier consolidation pass. It records SHA-256 digests, sizes, original aliases, and duplicate relationships for material that was reviewed during consolidation, but the corresponding paper files are intentionally absent from the compact master.

This keeps CryptoCave small, reproducible, and appropriate for GitHub while preserving enough metadata to identify previously reviewed sources if the original external archive is available later.
