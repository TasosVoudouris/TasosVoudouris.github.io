The first article developed the algebraic language of linear systems, vector spaces, bases, rank, kernels, and linear maps.

We now add the geometric machinery needed before lattice theory.

The central tension is this:

A lattice is generated by an integer basis:

\[
\boxed{
L(B)=B\mathbb Z^n,
}
\]

but many geometric questions about that lattice are easiest to answer using an **orthogonal real basis**.

Gram–Schmidt connects these two viewpoints.

Starting from:

\[
b_1,\ldots,b_n,
\]

it constructs orthogonal vectors:

\[
b_1^*,\ldots,b_n^*
\]

that preserve the same successive real subspaces while exposing lengths, projections, angles, and volume.

The central progression is:

\[
\boxed{
\text{projection}
\rightarrow
\text{Gram--Schmidt}
\rightarrow
\text{QR}
\rightarrow
\text{determinant}
\rightarrow
\text{volume}.
}
\]

These objects will later become fundamental in lattice reduction.

## Orthogonal projections

Let:

\[
u,v\in\mathbb R^n
\]

with:

\[
u\neq0.
\]

We want to decompose \(v\) into:

\[
\boxed{
v
=
v_{\parallel}
+
v_{\perp},
}
\]

where:

\[
v_{\parallel}
\]

lies in the line:

\[
\operatorname{span}(u),
\]

and:

\[
v_{\perp}
\]

is orthogonal to \(u\).

Since:

\[
v_{\parallel}=cu
\]

for some scalar \(c\), require:

\[
\langle v-cu,u\rangle=0.
\]

Then:

\[
\langle v,u\rangle
-
c\langle u,u\rangle
=
0.
\]

Therefore:

\[
\boxed{
c
=
\frac{
\langle v,u\rangle
}{
\langle u,u\rangle
}.
}
\]

So the orthogonal projection of \(v\) onto the line spanned by \(u\) is:

\[
\boxed{
\operatorname{proj}_u(v)
=
\frac{
\langle v,u\rangle
}{
\langle u,u\rangle
}
u.
}
\]

---

### The residual is orthogonal

Define:

\[
r
=
v-\operatorname{proj}_u(v).
\]

Then:

\[
\begin{aligned}
\langle r,u\rangle
&=
\left\langle
v-
\frac{
\langle v,u\rangle
}{
\langle u,u\rangle
}
u,
u
\right\rangle
\\
&=
\langle v,u\rangle
-
\frac{
\langle v,u\rangle
}{
\langle u,u\rangle
}
\langle u,u\rangle
\\
&=
0.
\end{aligned}
\]

Hence:

\[
\boxed{
v-\operatorname{proj}_u(v)
\perp u.
}
\]

This simple operation is the building block of Gram–Schmidt.

---

### Projection onto an orthogonal family

Suppose:

\[
u_1,\ldots,u_k
\]

are nonzero and mutually orthogonal.

Then the orthogonal projection of \(v\) onto their span is:

\[
\boxed{
\operatorname{proj}_{U}(v)
=
\sum_{j=1}^{k}
\frac{
\langle v,u_j\rangle
}{
\langle u_j,u_j\rangle
}
u_j.
}
\]

Because the \(u_j\) are orthogonal, their projection contributions do not interfere.

---

### Projection onto an orthonormal basis

If instead:

\[
q_1,\ldots,q_k
\]

are orthonormal:

\[
\langle q_i,q_j\rangle
=
\delta_{ij},
\]

then:

\[
\langle q_j,q_j\rangle=1.
\]

So the formula simplifies to:

\[
\boxed{
\operatorname{proj}_{U}(v)
=
\sum_{j=1}^{k}
\langle v,q_j\rangle q_j.
}
\]

If:

\[
Q=
\begin{pmatrix}
|&&|\\
q_1&\cdots&q_k\\
|&&|
\end{pmatrix},
\]

then:

\[
Q^TQ=I_k
\]

and the projection matrix is:

\[
\boxed{
P=QQ^T.
}
\]

Thus:

\[
\boxed{
\operatorname{proj}_{U}(v)
=
QQ^Tv.
}
\]

---

### Example

Let:

\[
u=
\begin{pmatrix}
1\\
1
\end{pmatrix},
\qquad
v=
\begin{pmatrix}
3\\
1
\end{pmatrix}.
\]

Then:

\[
\langle v,u\rangle
=
4
\]

and:

\[
\langle u,u\rangle
=
2.
\]

Therefore:

\[
\operatorname{proj}_u(v)
=
\frac42
\begin{pmatrix}
1\\
1
\end{pmatrix}
=
\begin{pmatrix}
2\\
2
\end{pmatrix}.
\]

The residual is:

\[
v-
\operatorname{proj}_u(v)
=
\begin{pmatrix}
1\\
-1
\end{pmatrix}.
\]

Indeed:

\[
\left\langle
\begin{pmatrix}
1\\
-1
\end{pmatrix},
\begin{pmatrix}
1\\
1
\end{pmatrix}
\right\rangle
=
0.
\]

So the decomposition is:

\[
\boxed{
\begin{pmatrix}
3\\
1
\end{pmatrix}
=
\begin{pmatrix}
2\\
2
\end{pmatrix}
+
\begin{pmatrix}
1\\
-1
\end{pmatrix}.
}
\]

## 2. Gram–Schmidt orthogonalization

Let:

\[
b_1,\ldots,b_n
\]

be linearly independent vectors in:

\[
\mathbb R^m.
\]

Gram–Schmidt constructs mutually orthogonal vectors:

\[
\boxed{
b_1^*,\ldots,b_n^*
}
\]

while preserving the same successive spans.

Start with:

\[
\boxed{
b_1^*=b_1.
}
\]

For:

\[
i\ge2,
\]

subtract from \(b_i\) its projections onto all previous orthogonal directions:

\[
\boxed{
b_i^*
=
b_i
-
\sum_{j=1}^{i-1}
\mu_{i,j}b_j^*,
}
\]

where:

\[
\boxed{
\mu_{i,j}
=
\frac{
\langle b_i,b_j^*\rangle
}{
\langle b_j^*,b_j^*\rangle
}.
}
\]

The numbers:

\[
\mu_{i,j}
\]

are the **Gram–Schmidt coefficients**.

They will later play a central role in lattice reduction.

---

### Why the vectors become orthogonal

Take:

\[
k<i.
\]

Then:

\[
\begin{aligned}
\langle b_i^*,b_k^*\rangle
&=
\left\langle
b_i-
\sum_{j<i}
\mu_{i,j}b_j^*,
b_k^*
\right\rangle.
\end{aligned}
\]

All terms with:

\[
j\neq k
\]

vanish because the previous \(b_j^*\) are mutually orthogonal.

So:

\[
\langle b_i^*,b_k^*\rangle
=
\langle b_i,b_k^*\rangle
-
\mu_{i,k}
\langle b_k^*,b_k^*\rangle.
\]

By definition of:

\[
\mu_{i,k},
\]

this equals zero.

Therefore:

\[
\boxed{
\langle b_i^*,b_j^*\rangle=0
\qquad
(i\neq j).
}
\]

---

### Successive spans are preserved

For each:

\[
k,
\]

Gram–Schmidt satisfies:

\[
\boxed{
\operatorname{span}
(b_1,\ldots,b_k)
=
\operatorname{span}
(b_1^*,\ldots,b_k^*).
}
\]

This is crucial.

We have changed the geometry of the basis representation without changing the subspace.

---

### A worked example

Take:

\[
b_1=
\begin{pmatrix}
1\\
1
\end{pmatrix},
\qquad
b_2=
\begin{pmatrix}
1\\
0
\end{pmatrix}.
\]

First:

\[
b_1^*
=
\begin{pmatrix}
1\\
1
\end{pmatrix}.
\]

Now compute:

\[
\mu_{2,1}
=
\frac{
\langle b_2,b_1^*\rangle
}{
\langle b_1^*,b_1^*\rangle
}.
\]

We have:

\[
\langle b_2,b_1^*\rangle=1
\]

and:

\[
\langle b_1^*,b_1^*\rangle=2.
\]

Thus:

\[
\boxed{
\mu_{2,1}
=
\frac12.
}
\]

Therefore:

\[
\begin{aligned}
b_2^*
&=
b_2
-
\frac12b_1^*
\\
&=
\begin{pmatrix}
1\\
0
\end{pmatrix}
-
\frac12
\begin{pmatrix}
1\\
1
\end{pmatrix}
\\
&=
\begin{pmatrix}
1/2\\
-1/2
\end{pmatrix}.
\end{aligned}
\]

Check:

\[
\left\langle
\begin{pmatrix}
1\\
1
\end{pmatrix},
\begin{pmatrix}
1/2\\
-1/2
\end{pmatrix}
\right\rangle
=
0.
\]

So:

\[
\boxed{
b_1^*\perp b_2^*.
}
\]

---

### The lattice warning

Suppose:

\[
b_1,b_2
\]

generate a lattice:

\[
L=
\mathbb Zb_1+\mathbb Zb_2.
\]

In the example:

\[
b_2^*
=
\frac12
\begin{pmatrix}
1\\
-1
\end{pmatrix}.
\]

This vector need not belong to:

\[
L.
\]

That is expected.

Gram–Schmidt uses real coefficients:

\[
\mu_{i,j}\in\mathbb R.
\]

Therefore:

\[
\boxed{
b_i^*
\text{ are geometric auxiliary vectors, not generally lattice vectors}.
}
\]

This distinction is essential in lattice algorithms.

---

### Two bases with different roles

We therefore carry two related collections:

\[
\boxed{
B=(b_1,\ldots,b_n)
}
\]

and:

\[
\boxed{
B^*=(b_1^*,\ldots,b_n^*).
}
\]

The original basis \(B\):

- consists of lattice vectors;
- generates the lattice over \(\mathbb Z\);
- may be geometrically poor.

The Gram–Schmidt family \(B^*\):

- is orthogonal;
- measures the geometry cleanly;
- usually does **not** generate the lattice over \(\mathbb Z\).

Lattice reduction will repeatedly move the first basis while monitoring the second.

---

## Orthonormal bases and QR decomposition

The Gram–Schmidt vectors are orthogonal but not necessarily of unit length.

Normalize them:

\[
\boxed{
q_i
=
\frac{
b_i^*
}{
\|b_i^*\|_2
}.
}
\]

Then:

\[
\|q_i\|_2=1
\]

and:

\[
\langle q_i,q_j\rangle=0
\qquad
(i\neq j).
\]

So:

\[
q_1,\ldots,q_n
\]

form an orthonormal family.

---

### Matrix form

Let:

\[
A=
\begin{pmatrix}
|&&|\\
b_1&\cdots&b_n\\
|&&|
\end{pmatrix}
\in
\mathbb R^{m\times n}
\]

with linearly independent columns.

Place the orthonormal vectors into:

\[
Q=
\begin{pmatrix}
|&&|\\
q_1&\cdots&q_n\\
|&&|
\end{pmatrix}.
\]

Then:

\[
\boxed{
Q^TQ=I_n.
}
\]

Each original vector \(b_i\) can be written in terms of:

\[
q_1,\ldots,q_i.
\]

Therefore:

\[
\boxed{
A=QR,
}
\]

where:

\[
R
\]

is upper triangular.

This is the **QR decomposition**.

---

### Relation with Gram–Schmidt coefficients

Since:

\[
b_j^*
=
\|b_j^*\|q_j,
\]

we have:

\[
b_i
=
b_i^*
+
\sum_{j<i}
\mu_{i,j}b_j^*.
\]

Therefore:

\[
b_i
=
\|b_i^*\|q_i
+
\sum_{j<i}
\mu_{i,j}
\|b_j^*\|q_j.
\]

Thus the upper-triangular matrix \(R\) encodes both:

\[
\mu_{i,j}
\]

and:

\[
\|b_i^*\|.
\]

In particular, its diagonal entries can be taken as:

\[
\boxed{
r_{ii}
=
\|b_i^*\|.
}
\]

---

### Volume from QR

Because \(Q\) is orthonormal, it does not distort Euclidean volume within the column space.

Therefore the volume determined by the columns of \(A\) is controlled entirely by \(R\).

Since \(R\) is triangular:

\[
\det R
=
\prod_{i=1}^{n}r_{ii}.
\]

Hence:

\[
\boxed{
\operatorname{vol}(b_1,\ldots,b_n)
=
\prod_{i=1}^{n}
\|b_i^*\|.
}
\]

This identity will be extremely useful in lattice theory.

---

### Numerical stability

The classical Gram–Schmidt formulas are ideal for mathematical derivations.

But when implemented using floating-point arithmetic, naive classical Gram–Schmidt can lose orthogonality when the input vectors are nearly linearly dependent.

Numerical linear algebra therefore often prefers:

- modified Gram–Schmidt;
- Householder reflections;
- Givens rotations.

These are more stable computationally.

The distinction is important:

\[
\boxed{
\text{mathematical definition}
\neq
\text{best floating-point implementation}.
}
\]

For exact derivations in lattice theory, however, the classical coefficients:

\[
\mu_{i,j}
\]

remain the natural language.

---

## Determinants and volume

Let:

\[
B\in\mathbb R^{n\times n}
\]

be square.

The determinant:

\[
\det B
\]

has several interpretations.

Algebraically, it detects invertibility:

\[
\boxed{
B\text{ invertible}
\iff
\det B\neq0.
}
\]

Geometrically, its absolute value measures volume scaling.

---

### Volume of a parallelepiped

Let the columns of \(B\) be:

\[
b_1,\ldots,b_n.
\]

The associated fundamental parallelepiped is:

\[
\boxed{
P(B)
=
\left\{
\sum_{i=1}^{n}
t_i b_i:
0\le t_i<1
\right\}.
}
\]

Its \(n\)-dimensional volume is:

\[
\boxed{
\operatorname{vol}(P(B))
=
|\det B|.
}
\]

---

### Two-dimensional example

Let:

\[
B=
\begin{pmatrix}
2&1\\
0&3
\end{pmatrix}.
\]

Then:

\[
\det B
=
6.
\]

Therefore the parallelogram generated by:

\[
b_1=
\begin{pmatrix}
2\\
0
\end{pmatrix},
\qquad
b_2=
\begin{pmatrix}
1\\
3
\end{pmatrix}
\]

has area:

\[
\boxed{
6.
}
\]

---

### Orientation versus volume

The sign of the determinant records orientation.

For volume, only the magnitude matters:

\[
\boxed{
|\det B|.
}
\]

Exchanging two basis vectors changes:

\[
\det B
\]

to:

\[
-\det B,
\]

but the geometric region has the same volume.

---

### Scaling one basis vector

If one column is multiplied by:

\[
c,
\]

then:

\[
\det B
\]

is also multiplied by \(c\).

Thus geometric volume scales by:

\[
|c|.
\]

For example, replacing:

\[
b_1
\]

with:

\[
2b_1
\]

doubles the parallelepiped volume.

This will later explain why some real basis transformations change the lattice itself.

---

### Determinant and Gram–Schmidt

For a square basis matrix \(B\), QR gives:

\[
B=QR.
\]

Since \(Q\) is orthogonal:

\[
|\det Q|=1.
\]

Therefore:

\[
|\det B|
=
|\det R|.
\]

Because \(R\) is triangular:

\[
|\det R|
=
\prod_i|r_{ii}|.
\]

Using:

\[
r_{ii}
=
\|b_i^*\|,
\]

we obtain:

\[
\boxed{
|\det B|
=
\prod_{i=1}^{n}
\|b_i^*\|.
}
\]

This is the square-basis form of the Gram–Schmidt volume identity.

---

## Gram matrices and rectangular bases

Lattice bases do not always form square matrices.

We may have:

\[
n
\]

linearly independent vectors in:

\[
\mathbb R^m
\]

with:

\[
n\le m.
\]

Then the basis matrix:

\[
B\in\mathbb R^{m\times n}
\]

is rectangular.

There is no ordinary determinant:

\[
\det B.
\]

But the generated \(n\)-dimensional parallelepiped still has an \(n\)-dimensional volume.

The correct object is the **Gram matrix**.

---

### Gram matrix

For column vectors:

\[
b_1,\ldots,b_n,
\]

define:

\[
\boxed{
G
=
B^TB.
}
\]

Its entries are:

\[
\boxed{
G_{ij}
=
\langle b_i,b_j\rangle.
}
\]

So the Gram matrix records all pairwise inner products.

---

### Properties

If the columns of \(B\) are linearly independent, then:

\[
G=B^TB
\]

is symmetric positive definite.

Indeed, for:

\[
x\neq0,
\]

\[
x^TGx
=
x^TB^TBx
=
\|Bx\|_2^2.
\]

Since \(B\) has full column rank:

\[
Bx\neq0.
\]

Therefore:

\[
\boxed{
x^TGx>0.
}
\]

---

### Gram determinant

The squared \(n\)-dimensional volume of the parallelepiped generated by the columns is:

\[
\boxed{
\det(B^TB).
}
\]

Therefore:

\[
\boxed{
\operatorname{vol}
(b_1,\ldots,b_n)
=
\sqrt{
\det(B^TB)
}.
}
\]

This works even when:

\[
B
\]

is rectangular.

---

### Why it agrees with the ordinary determinant

If:

\[
B\in\mathbb R^{n\times n},
\]

then:

\[
\det(B^TB)
=
\det(B^T)\det(B).
\]

Since:

\[
\det(B^T)=\det B,
\]

we obtain:

\[
\det(B^TB)
=
(\det B)^2.
\]

Therefore:

\[
\boxed{
\sqrt{
\det(B^TB)
}
=
|\det B|.
}
\]

So the Gram formula genuinely extends the ordinary determinant-volume formula.

---

### Gram determinant and QR

If:

\[
B=QR
\]

with:

\[
Q^TQ=I,
\]

then:

\[
B^TB
=
R^TQ^TQR
=
R^TR.
\]

Hence:

\[
\det(B^TB)
=
(\det R)^2.
\]

Therefore:

\[
\sqrt{
\det(B^TB)
}
=
|\det R|.
\]

And because:

\[
r_{ii}
=
\|b_i^*\|,
\]

we again recover:

\[
\boxed{
\sqrt{
\det(B^TB)
}
=
\prod_{i=1}^{n}
\|b_i^*\|.
}
\]

Thus three apparently different constructions give the same volume:

\[
\boxed{
\text{Gram determinant}
=
\text{QR diagonal product}
=
\text{Gram--Schmidt length product}.
}
\]

---

### Example in \(\mathbb R^3\)

Take:

\[
b_1=
\begin{pmatrix}
1\\
0\\
1
\end{pmatrix},
\qquad
b_2=
\begin{pmatrix}
0\\
1\\
1
\end{pmatrix}.
\]

Then:

\[
B=
\begin{pmatrix}
1&0\\
0&1\\
1&1
\end{pmatrix}.
\]

The Gram matrix is:

\[
B^TB
=
\begin{pmatrix}
2&1\\
1&2
\end{pmatrix}.
\]

Its determinant is:

\[
4-1=3.
\]

Therefore the area of the parallelogram inside its two-dimensional span is:

\[
\boxed{
\sqrt3.
}
\]

Even though:

\[
B
\]

is \(3\times2\), its intrinsic two-dimensional volume is perfectly well defined.

## Basis changes and lattice invariants

For ordinary vector spaces, any invertible real change of basis is allowed.

Suppose:

\[
B
\]

is a basis matrix and:

\[
M\in GL_n(\mathbb R).
\]

Then:

\[
BM
\]

has the same real column span as \(B\).

So:

\[
\boxed{
\operatorname{span}_{\mathbb R}(B)
=
\operatorname{span}_{\mathbb R}(BM).
}
\]

For lattices, this is not enough.

---

### Lattice basis change

Suppose:

\[
L(B)=B\mathbb Z^n.
\]

Another matrix:

\[
B'
\]

generates the same lattice exactly when:

\[
\boxed{
B'=BU
}
\]

for a unimodular integer matrix:

\[
\boxed{
U\in GL_n(\mathbb Z).
}
\]

Such a matrix satisfies:

\[
\boxed{
\det U=\pm1.
}
\]

Its inverse is also integral.

Therefore:

\[
U\mathbb Z^n
=
\mathbb Z^n.
\]

Hence:

\[
\begin{aligned}
L(BU)
&=
BU\mathbb Z^n\\
&=
B\mathbb Z^n\\
&=
L(B).
\end{aligned}
\]

---

### Determinant preservation

For a square lattice basis:

\[
B'=BU.
\]

Then:

\[
\det(B')
=
\det(B)\det(U).
\]

Since:

\[
\det(U)=\pm1,
\]

we obtain:

\[
\boxed{
|\det(B')|
=
|\det(B)|.
}
\]

Thus the lattice volume is independent of the chosen integer basis.

This invariant is called the **lattice determinant** or **covolume**.

For full-rank:

\[
L\subset\mathbb R^n,
\]

\[
\boxed{
\det(L)
=
|\det B|.
}
\]

---

### Rectangular lattice basis

Suppose:

\[
B\in\mathbb R^{m\times n}
\]

has full column rank.

Then the lattice lives in the \(n\)-dimensional subspace:

\[
\operatorname{span}_{\mathbb R}(B)
\subseteq
\mathbb R^m.
\]

Its intrinsic determinant is:

\[
\boxed{
\det(L)
=
\sqrt{
\det(B^TB)
}.
}
\]

Now change basis:

\[
B'=BU
\]

with:

\[
U\in GL_n(\mathbb Z).
\]

Then:

\[
B'^TB'
=
U^TB^TBU.
\]

Therefore:

\[
\det(B'^TB')
=
\det(U)^2
\det(B^TB).
\]

Since:

\[
\det(U)^2=1,
\]

we obtain:

\[
\boxed{
\det(B'^TB')
=
\det(B^TB).
}
\]

Thus:

\[
\boxed{
\det(L)
}
\]

is basis-independent in the rectangular case as well.

---

### Same real span, different lattice

Consider:

\[
B=
\begin{pmatrix}
1&0\\
0&1
\end{pmatrix}.
\]

Then:

\[
L(B)=\mathbb Z^2.
\]

Now take:

\[
M=
\begin{pmatrix}
2&0\\
0&1
\end{pmatrix}.
\]

This matrix is invertible over:

\[
\mathbb R,
\]

so:

\[
BM
\]

is still a basis of:

\[
\mathbb R^2.
\]

But:

\[
\det M=2,
\]

so:

\[
M\notin GL_2(\mathbb Z).
\]

The generated lattice becomes:

\[
\boxed{
2\mathbb Z\times\mathbb Z,
}
\]

which is a proper sublattice of:

\[
\mathbb Z^2.
\]

Its determinant is:

\[
2,
\]

while:

\[
\det(\mathbb Z^2)=1.
\]

So:

\[
\boxed{
\text{invertible real basis change}
}
\]

does not necessarily preserve the lattice.

Only unimodular integer changes do.

---

## Why these quantities matter for lattices

The linear-algebra machinery developed here will be reused almost unchanged in lattice algorithms.

The important difference is that the original basis must remain an integer basis of the same lattice.

---

### Gram–Schmidt coefficients measure skew

Recall:

\[
\boxed{
\mu_{i,j}
=
\frac{
\langle b_i,b_j^*\rangle
}{
\langle b_j^*,b_j^*\rangle
}.
}
\]

If:

\[
|\mu_{i,j}|
\]

is large, then \(b_i\) contains a large component in the direction of:

\[
b_j^*.
\]

Lattice reduction algorithms try to modify the integer basis so these coefficients become better controlled.

---

### Size reduction

Suppose:

\[
\mu_{i,j}
\]

is close to an integer:

\[
k.
\]

Replacing:

\[
b_i
\]

by:

\[
\boxed{
b_i-kb_j
}
\]

is allowed because:

\[
k\in\mathbb Z.
\]

This corresponds to a unimodular basis transformation.

The lattice therefore remains unchanged.

Geometrically, however, the new basis may be shorter and less skewed.

This is the essential mechanism behind **size reduction**.

---

### Why we cannot simply replace \(b_i\) by \(b_i^*\)

Gram–Schmidt gives an ideal orthogonal system:

\[
b_i^*.
\]

One might ask:

> Why not simply use the orthogonalized vectors as the lattice basis?

Because:

\[
b_i^*
=
b_i
-
\sum_{j<i}
\mu_{i,j}b_j^*
\]

contains real coefficients.

In general:

\[
\mu_{i,j}\notin\mathbb Z.
\]

So:

\[
b_i^*
\]

need not belong to the lattice.

Therefore lattice reduction cannot arbitrarily orthogonalize the basis.

It must approximate geometric improvement while staying inside:

\[
GL_n(\mathbb Z).
\]

This constraint is the heart of lattice reduction.

---

### Orthogonality defect intuition

An orthogonal basis is geometrically ideal because:

\[
\operatorname{vol}(b_1,\ldots,b_n)
=
\prod_i\|b_i\|.
\]

For a nonorthogonal basis, Hadamard's inequality gives:

\[
\boxed{
\operatorname{vol}
(b_1,\ldots,b_n)
\le
\prod_{i=1}^{n}\|b_i\|.
}
\]

Equality occurs exactly when the vectors are mutually orthogonal.

Therefore the ratio:

\[
\boxed{
\frac{
\prod_i\|b_i\|
}{
\operatorname{vol}(b_1,\ldots,b_n)
}
}
\]

measures how far a basis is from being orthogonal in one useful sense.

The lattice determinant stays fixed under unimodular basis changes.

So improving the basis means reducing unnecessary vector lengths and skew while preserving:

\[
\boxed{
\det(L).
}
\]

---

### Gram–Schmidt lengths and volume

We established:

\[
\boxed{
\det(L)
=
\prod_{i=1}^{n}
\|b_i^*\|
}
\]

for a full-rank lattice in its span.

This is a crucial invariant.

A lattice algorithm may drastically alter:

\[
b_1,\ldots,b_n,
\]

but if the transformation is unimodular, the product:

\[
\prod_i\|b_i^*\|
\]

remains equal to the same lattice covolume.

The individual Gram–Schmidt lengths can change.

Their product cannot.

---

### The LLL preview

The Lenstra–Lenstra–Lovász algorithm will combine two ideas:

1. **size reduction**, controlling:
   \[
   \mu_{i,j};
   \]
2. a geometric condition comparing successive Gram–Schmidt lengths.

The important point here is not the exact LLL condition yet.

It is the architecture:

\[
\boxed{
\text{integer basis operations}
}
\]

are guided by:

\[
\boxed{
\text{real Gram--Schmidt geometry}.
}
\]

That is the central bridge from linear algebra to lattice algorithms.

---

## A complete worked example

Let:

\[
b_1=
\begin{pmatrix}
2\\
0
\end{pmatrix},
\qquad
b_2=
\begin{pmatrix}
1\\
3
\end{pmatrix}.
\]

The basis matrix is:

\[
B=
\begin{pmatrix}
2&1\\
0&3
\end{pmatrix}.
\]

---

### Step 1 — Lattice determinant

Since \(B\) is square:

\[
\det(B)
=
6.
\]

Therefore:

\[
\boxed{
\det(L)=6.
}
\]

---

### Step 2 — Gram–Schmidt

First:

\[
b_1^*
=
b_1
=
\begin{pmatrix}
2\\
0
\end{pmatrix}.
\]

Now:

\[
\mu_{2,1}
=
\frac{
\langle b_2,b_1^*\rangle
}{
\langle b_1^*,b_1^*\rangle
}.
\]

We have:

\[
\langle b_2,b_1^*\rangle
=
2
\]

and:

\[
\langle b_1^*,b_1^*\rangle
=
4.
\]

Therefore:

\[
\boxed{
\mu_{2,1}
=
\frac12.
}
\]

Then:

\[
b_2^*
=
b_2-
\frac12b_1^*.
\]

So:

\[
b_2^*
=
\begin{pmatrix}
1\\
3
\end{pmatrix}
-
\begin{pmatrix}
1\\
0
\end{pmatrix}
=
\begin{pmatrix}
0\\
3
\end{pmatrix}.
\]

Thus:

\[
\boxed{
b_1^*
=
\begin{pmatrix}
2\\
0
\end{pmatrix},
\qquad
b_2^*
=
\begin{pmatrix}
0\\
3
\end{pmatrix}.
}
\]

---

### Step 3 — Volume from Gram–Schmidt lengths

We have:

\[
\|b_1^*\|=2
\]

and:

\[
\|b_2^*\|=3.
\]

Therefore:

\[
\prod_i\|b_i^*\|
=
2\cdot3
=
6.
\]

This agrees with:

\[
|\det B|=6.
\]

So:

\[
\boxed{
|\det B|
=
\|b_1^*\|
\|b_2^*\|.
}
\]

---

### Step 4 — Unimodular basis change

Take:

\[
U=
\begin{pmatrix}
1&-1\\
0&1
\end{pmatrix}.
\]

Then:

\[
\det(U)=1.
\]

So:

\[
U\in GL_2(\mathbb Z).
\]

The new basis matrix is:

\[
B'=BU.
\]

Thus:

\[
B'
=
\begin{pmatrix}
2&-1\\
0&3
\end{pmatrix}.
\]

This changes the second basis vector from:

\[
b_2
\]

to:

\[
b_2-b_1.
\]

But:

\[
\boxed{
L(B')=L(B).
}
\]

And:

\[
|\det B'|
=
6.
\]

The basis changed.

The lattice did not.

---

## The structural picture

The geometry begins with projection:

\[
\boxed{
\operatorname{proj}_u(v)
=
\frac{
\langle v,u\rangle
}{
\langle u,u\rangle
}u.
}
\]

Repeated projection gives Gram–Schmidt:

\[
\boxed{
b_i^*
=
b_i
-
\sum_{j<i}
\mu_{i,j}b_j^*.
}
\]

Normalization produces:

\[
\boxed{
A=QR.
}
\]

The diagonal of \(R\) records:

\[
\boxed{
\|b_i^*\|.
}
\]

Their product gives volume:

\[
\boxed{
\operatorname{vol}
=
\prod_i\|b_i^*\|.
}
\]

For a square basis:

\[
\boxed{
\operatorname{vol}
=
|\det B|.
}
\]

For a rectangular full-column-rank basis:

\[
\boxed{
\operatorname{vol}
=
\sqrt{
\det(B^TB)
}.
}
\]

For a lattice:

\[
\boxed{
B'
=
BU,
\qquad
U\in GL_n(\mathbb Z)
}
\]

preserves that volume.

Therefore:

\[
\boxed{
\det(L)
}
\]

is an invariant of the lattice, not of one particular basis.

So the complete chain is:

\[
\boxed{
\text{projection}
\rightarrow
\text{orthogonalization}
\rightarrow
\text{QR}
\rightarrow
\text{volume}
\rightarrow
\text{lattice determinant}.
}
\]
