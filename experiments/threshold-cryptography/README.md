# Secret Sharing & Threshold Cryptography experiments

Companion code for the ordered CryptoCave series:

1. additive secret sharing
2. Shamir secret sharing
3. interpolation benchmarks (SageMath research bundle)
4. packed secret sharing
5. polynomial splitting / roots of unity
6. FFT-based packed secret sharing
7. robust reconstruction / Gao decoding

The DKG, multisignature-comparison, and distributed-randomness articles are protocol notes and therefore do not pretend to have a secure production implementation in this folder.

Run all dependency-free toy checks with:

```bash
python run_all.py
```
