# References and implementation anchors

The following primary or maintained sources support the mathematical and
development path used in these chapters.

1. Adi Shamir, “How to Share a Secret,” *Communications of the ACM*, 1979.
   [DOI: 10.1145/359168.359176](https://doi.org/10.1145/359168.359176)

2. Irving S. Reed and Gustave Solomon, “Polynomial Codes over Certain Finite
   Fields,” *Journal of the Society for Industrial and Applied Mathematics*,
   1960. [DOI: 10.1137/0108018](https://doi.org/10.1137/0108018)

3. Donald Beaver, “Efficient Multiparty Protocols Using Circuit Randomization,”
   *CRYPTO 1991*. [DOI: 10.1007/3-540-46766-1_34](https://doi.org/10.1007/3-540-46766-1_34)

4. Paul Feldman, “A Practical Scheme for Non-interactive Verifiable Secret
   Sharing,” *28th Annual Symposium on Foundations of Computer Science*, 1987.
   [DOI: 10.1109/SFCS.1987.4](https://doi.org/10.1109/SFCS.1987.4)

5. Torben Pryds Pedersen, “Non-Interactive and Information-Theoretic Secure
   Verifiable Secret Sharing,” *CRYPTO 1991*.
   [DOI: 10.1007/3-540-46766-1_9](https://doi.org/10.1007/3-540-46766-1_9)

6. Rosario Gennaro, Stanisław Jarecki, Hugo Krawczyk, and Tal Rabin, “Secure
   Distributed Key Generation for Discrete-Log Based Cryptosystems,” *Journal
   of Cryptology*, vol. 20, pp. 51–83, 2007.
   [DOI: 10.1007/s00145-006-0347-3](https://doi.org/10.1007/s00145-006-0347-3)

7. Deirdre Connolly, Chelsea Komlo, Ian Goldberg, and Christopher A. Wood, “The
   Flexible Round-Optimized Schnorr Threshold (FROST) Protocol for Two-Round
   Schnorr Signatures,” RFC 9591, 2024.
   [RFC Editor](https://www.rfc-editor.org/rfc/rfc9591.html)

8. Chelsea Komlo and Ian Goldberg, “FROST: Flexible Round-Optimized Schnorr
   Threshold Signatures,” IACR ePrint 2020/852, 2020.
   [IACR ePrint](https://eprint.iacr.org/2020/852)

9. NIST, *Threshold Schemes for Cryptographic Primitives*, NISTIR 8214, 2019.
   [NIST publication page](https://csrc.nist.gov/pubs/ir/8214/final)

10. NIST, *First Call for Multi-Party Threshold Schemes*, NISTIR 8214C, 2026.
   [NIST publication page](https://csrc.nist.gov/pubs/ir/8214/c/final)

11. Zcash Foundation, maintained Rust implementations of RFC 9591 FROST.
   [GitHub repository](https://github.com/ZcashFoundation/frost)

12. Thomas Ruffing, Viktoria Ronge, Elliott Jin, Jonas Schneider-Bensch, and
    Dominique Schröder, “ROAST: Robust Asynchronous Schnorr Threshold
    Signatures,” IACR ePrint 2022/550, 2022.
    [IACR ePrint](https://eprint.iacr.org/2022/550)

13. Marcel Keller, MP-SPDZ: a maintained multi-protocol framework for MPC
    experiments in passive and malicious security models.
    [GitHub repository](https://github.com/data61/MP-SPDZ)

14. OpenFHE, maintained homomorphic-encryption library with threshold BGV, BFV,
    and CKKS functionality.
    [Documentation](https://openfhe-development.readthedocs.io/)

15. Jiancheng Yang et al., “MedMNIST v2—A Large-Scale Lightweight Benchmark for
    2D and 3D Biomedical Image Classification,” *Scientific Data*, 2023.
    [Project and dataset](https://medmnist.com/)

Version 0.5 preserves selected original VSS scripts only as quarantined
provenance. No third-party bundled repository, credential, screenshot, or PDF is
copied into the active implementation.
