# RSA reference-basics companion

This is the small reviewed RSA example set recovered from the earlier CryptoCave repository. The main site uses the newer RSA Deep Dives as the canonical narrative; these scripts remain useful as compact executable references for textbook RSA, common-modulus recovery, low-exponent examples, and shared-prime failures.

Run from the repository root:

```bash
python -m unittest -v experiments/rsa/reference-basics/tests/test_rsa_examples.py
```
