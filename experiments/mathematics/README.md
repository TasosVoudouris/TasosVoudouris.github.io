# Mathematics companion material

This directory contains the **clean active companions** selected from `Mathematics.zip` during the v6.4 consolidation.

- `abstract-algebra/` — compact Sage examples for groups, rings, fields, modules, and polynomial irreducibility.
- `finite-fields/` — tested Python prime-field arithmetic plus Sage root/factorization reference code.
- `number-theory/` — tested Python arithmetic functions and Gaussian integers plus selected Sage reference programs for Gauss sums, norm equations, prime forms, and index calculus.
- `linear-algebra-lattices/` — tested dependency-free Gram–Schmidt and educational LLL implementation.
- `elliptic-curves/` — selected Sage references for division polynomials, associativity checks, Schoof, and isogeny neighbors.

The exact incoming archive is **not** duplicated here. It belongs only in the FULL master under `.local-reference-library/source-batches/Mathematics.zip` and is catalogued in `site-planning/mathematics-source-ledger.csv`.

Sage files are preserved as educational/reference companions unless separately validated. The Python companions in this directory are executed by the v6.4 validation pass.
