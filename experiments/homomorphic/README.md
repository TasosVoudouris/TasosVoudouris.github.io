# Homomorphic-encryption companion material

This directory consolidates the executable and notebook material recovered from the older CryptoCave homomorphic-encryption folder.

- `overview/`: introductory/RLWE experiments.
- `goldwasser-micali/`, `benaloh/`, `damgard-jurik/`, `naccache-stern/`, `okamoto-uchiyama/`: PHE teaching scripts.
- `somewhat-homomorphic/`, `dghv/`, `bgv/`: later-generation HE experiments.
- `lhe-reference/`: extracted code from the former nested `LHE-main.zip`.

**Validation status:** these files are retained as research/educational experiments. Syntax compilation is checked during consolidation, but unlike the reviewed hash, Matsui, Kasiski, RSA, and threshold packages, this directory does not yet have a unified passing test suite. Do not present it as production cryptography.
